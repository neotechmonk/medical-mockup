# Workflow

## Working rules (from the owner)
- Parallel work with multiple agents is a must. Separate agents own separate concerns and do not block each other.
- Delegation from voice to a coordinating agent is expected.
- Keep replies succinct; do the work instead of narrating it. "Stop" or "pause" means stop immediately.
- Sort permissions once, not repeatedly.
- Capture knowledge here and in project memory so the owner never repeats themselves.

## Where things live
- Notes: `notes/`. Public previews: `docs/` (GitHub Pages). Sources: `src/`.
- Design canvas (private): Version A artifact https://claude.ai/artifact/TwpCBa7cx6npKf2YKFnqJG holds Main, Service copy review, Palette exploration and Layout options. Version B: https://claude.ai/artifact/JD7YnWveWo12vmrzFyzefT

## Previews
1. Build or export a static HTML preview into `docs/`.
2. Add it to `docs/index.html`.
3. Commit and push to `main`; Pages publishes `/docs`.
4. Previews carry `noindex`; they are for review, not search.

## Then
Translate the chosen palette, layout and copy into Squarespace (single-page landing).
